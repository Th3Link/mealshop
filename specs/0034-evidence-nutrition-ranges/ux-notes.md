# Nutrition uncertainty in the native client

Keep the existing recipe layout. A compact native warning-colored indicator with the word
"Estimated" identifies affected inputs; color alone never carries meaning. Show aggregate/portion ranges in the existing nutrient table; keep ingredient rows compact.
Reported values remain ordinary values. An incomplete range names missing inputs and labels its
covered subtotal. Comparison sources, method and per-100-g facts remain inspectable below nutrition.
Use native Nextcloud warning tokens/components, stable accessible names and exact locale formatting;
no new palette, decorative cards, global reset or mandatory disclosure to read recipe parts.

Ingredient editing offers a value or an explicit lower/upper range per nutrient. Evidence remains
required. Group inheritance carries ranges and source identity. Missing constituent effects remain
separate; neither comparative composition nor a numeric zero establishes allergen safety.

Unsupported core contributions receive a separate warning, labelled "Nutrition incomplete".
They never borrow an arbitrary comparison or look like a complete zero. This applies to custom
ingredients as well. Private source review requires explicit permission and does not replace the
incomplete state when an ingredient lacks sufficient evidence.
