# Native productivity application

The screen's job is entering a recipe or ingredient without losing context. Nextcloud components, font, theme and navigation take precedence over website generators. UI UX Pro Max Quick Reference supplies field grouping, optional disclosure, visible labels, inline errors and focus recovery. Taste supplies aligned edges, restrained density, consistent control rhythm and screenshot inspection, without replacing the host UI with heroes, palettes, fonts or effects.

Ingredient editing: short identity section, explicit nutrient mode, common nutrients first, optional micronutrients, separately addable constituents, and collapsible classification/composition/provenance. Keep error drafts and announce saving. A name entered in recipe search becomes a create action in that same dropdown; cancelled creation retains the row.

Recipe editing: identity, ingredients with optional named parts, and ordered steps. Each ingredient belongs to one part or the main recipe. Step selectors assign ingredient rows and prepared parts. Part removal moves its rows/steps to the main recipe and clears dangling references after confirmation. No drag-only controls. Existing time budgets remain conservative and sequential; this slice does not promise a parallel schedule.

Household selection uses an external label and readable wrapping names; ingredient options show name and useful form context rather than truncating the middle. Native component focus styles remain intact. Test empty search, create/cancel/save, long names, German aliases, nested modal focus, own/unknown/zero values, mobile and dark mode.
