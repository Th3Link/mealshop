# UX notes

Keep the existing Material components, type scale and themes. One question per screen, a visible
step count, a primary action at the bottom and a quiet "Skip" beside it. Options are large tappable
cards or chips (diet presets, common allergens, common dislikes); free text and dictation are the
second path, never the only one.

- Welcome: one sentence on what the assistant sets up and that everything stays on this device.
- Main user: name → diet → allergies/intolerances → dislikes → (goals) → (dishes) → summary.
  The summary lists exactly what will be saved, with hard rules visually distinct from dislikes.
- Further people: "Add another person" or "Done". Name alone is enough; details can follow later.
- Calibration: cards with picture or icon, title and three or four tags; like / neutral / not for
  me, with an optional drag order of the liked ones. Never more than about twelve cards.
- Consent: its own screen, neutral wording, no pre-ticked agreement, equal-weight buttons, a
  link to the privacy summary and a note that sharing is not available yet.
- On-device Home and More show no household row. More gets "Start assistant" and "Privacy".
- Dictation: a microphone button on text answers, a visible listening state, the recognised text
  inserted for review, and a clear statement that recognition runs on the device.
- Check DE/EN, light/dark, 320 dp at 200 % text scale, Back behaviour and screen-reader order.
