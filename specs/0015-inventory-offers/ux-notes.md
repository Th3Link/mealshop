# Native household stock and offers

Use the existing Nextcloud shell, components, MDI icons, theme tokens and EN/DE messages. This is a
household tool, not a marketing page: Taste informs alignment, density and plain action labels;
its hero/palette/font/effect/navigation recipes do not apply. UX-UI Pro Max informs visible labels,
confirmation, keyboard order and recovery.

Inventory opens with searchable lots and exact remaining/reserved/available quantities, location,
batch and optional date. Add a lot in context; metadata editing, observed-quantity correction and
archive are separate actions. Empty stock invites entry, never implies missing food is zero.

Shopping links to a stock review: select contributions and use date, preview exact lot reservations
and remaining purchases, then explicitly confirm. Reserving never consumes stock. Held, used and
released allocations are named; covered rows cannot be mistaken for purchased tiles. Source changes
release obsolete holds; physical consumption remains an explicit historical fact.

Purchase receipt entry and completed-cooking consumption each preview before/after balances and
source references. Exact matching uses IDs and dimensions, not names or universal density. Missing
stock stays visible as unbooked requirements. History supports explicit reversal with a reason;
negative or over-reserved balances are blocked with recovery guidance.

Offers have shop, explicit ingredient/product binding, package quantity, price/currency, date range
and user-entered source. Default to a labelled shopping date and all household profiles; a writer
can choose intended profiles. Known exclusions block adding to shopping; unknown safety needs review.
No scraping, automatic substitutions, shopping or stock booking.

Use one labelled review surface with a before/after summary. Disable repeated submits; an ambiguous
submission freezes its body/key for retry. Definite conflicts retain edits and require reload/review.
Leaving drafts asks explicitly. Readers can inspect but cannot preview/confirm mutations. Verify real
Nextcloud routes, keyboard/focus, EN/DE, light/dark, reduced motion and 1440/390/320 px with axe/screens.
