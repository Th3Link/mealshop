# Grouped ingredient discovery

Native list rows replace repeated organizational source/record-ID metadata with a group name, subtype
count, expansion action and a separate details link. Search reveals subtype results directly; clearing
search restores the user's browsing expansion. Ingredient selectors retain their own food identity and
use parent context for search, not automatic replacement or nutrition inheritance. Group titles are
English base names with German translations; the mapping contains no health, vegan or allergen claims.
