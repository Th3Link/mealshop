# Approved concept screens

Customer-approved German design references from 2026-11-10. These PNGs are drawings, not native browser acceptance screenshots. The concept is general-purpose; the bread example illustrates parallel prepared parts, merging and an actual completion-triggered timer.

| Screen | Interaction |
| --- | --- |
| [Shared calendar](nextcloud-v3-01-gemeinsamer-speiseplan.png) | Meals and preparation in one meal plan |
| [Mealprep allocation](nextcloud-v3-02-mealprep-verteilen.png) | One production, several eating days |
| [Recipe editing](nextcloud-v3-03-allgemeines-rezept-bearbeiten.png) | General ingredients and instructions |
| [Cooking](nextcloud-v3-04-zubereitung.png) | Next action and waiting timer |
| [Sourdough editing](brot-mehrteilig-v4-01-sauerteig-bearbeiten.png) | Ingredients owned by a prepared part |
| [Combining parts](brot-mehrteilig-v4-02-vorstufen-zusammenfuehren.png) | Reuse prepared parts without duplicate ingredients |
| [Bread in the calendar](brot-mehrteilig-v4-03-brot-im-speiseplan.png) | Preparation alongside meals |
| [Finishing mixing](brot-mehrteilig-v4-04-quellteig-fertig.png) | Completion starts the waiting time |
| [Waiting](brot-mehrteilig-v4-05-quellzeit-laeuft.png) | Remaining time from the actual action |
