# MealShop product and agent specification pack

This folder is designed to be copied into the root of the MealShop repository.

- `AGENTS.md` — guardrails and workflow for coding agents (merge with an existing AGENTS.md if present).
- `docs/PRODUCT_VISION.md` — product intent, scope and non-goals.
- `docs/UX_SPEC.md` — mobile navigation, onboarding and core flows.
- `docs/DOMAIN_MODEL.md` — conceptual entities, invariants and boundaries.
- `docs/IMPLEMENTATION_PLAN.md` — phased backlog, acceptance criteria and first agent prompt.
- `docs/DECISIONS.md` — decisions to confirm and open questions.

**Important:** This pack is derived from product discussion. It has not been reconciled against the live repository. The first coding-agent task is an evidence-based repository audit, not feature implementation.

Suggested commit message: `docs: define MealShop mobile product vision and agent roadmap`
